# TC-SET_01: 설정 홈에서 일반 화면 진입 시 정보 항목 표시

## 목적
설정 홈에서 일반 화면 진입 시 정보 항목 표시

## 플랫폼
- iOS

## 전제조건
- 설정 앱(com.apple.Preferences)을 실행한 상태

## 테스트 케이스 1

### 테스트 함수명
`test_설정_홈에서_일반_화면_진입_시_정보_항목_표시`

### 단계
1. 설정 홈에서 '일반' 항목을 누른다

### 기대결과
- 일반 화면 상단에 '일반' 제목이 표시되고 '정보' 항목이 보인다.
- 일반
- 정보
