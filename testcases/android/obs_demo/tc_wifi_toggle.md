# TC: Wi-Fi 토글 동작 확인

## 기본 정보
- **플랫폼**: android
- **TC ID**: tc_wifi_toggle
- **그룹**: obs_demo
- **우선순위**: High

## 사전 조건
- Android 에뮬레이터 또는 실기기 연결
- Settings 앱 설치됨

## 테스트 단계
1. Settings 앱 실행
2. "Network & internet" 메뉴 탭
3. Wi-Fi 토글 확인
4. Wi-Fi 현재 상태(ON/OFF) 읽기

## 예상 결과
- Wi-Fi 토글 요소가 존재함
- 토글 상태(ON/OFF)가 정확히 표시됨
