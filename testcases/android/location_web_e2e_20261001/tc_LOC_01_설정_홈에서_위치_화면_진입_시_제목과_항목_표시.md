# TC-LOC_01: 설정 홈에서 위치 화면 진입 시 제목과 항목 표시

## 목적
설정 홈에서 위치 화면 진입 시 제목과 항목 표시

## 플랫폼
- Android

## 전제조건
- 설정 앱(com.android.settings/.homepage.SettingsHomepageActivity)을 실행한 상태

## 테스트 케이스 1

### 테스트 함수명
`test_설정_홈에서_위치_화면_진입_시_제목과_항목_표시`

### 단계
1. 설정 홈에서 '위치' 항목을 누른다

### 기대결과
- 위치 화면 상단에 '위치' 제목이 표시되고 '위치 사용'과 '위치 서비스' 항목이 보인다.
- 위치
- 위치 사용
- 위치 서비스
