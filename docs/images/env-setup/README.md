2026-10-02에 현재 앱 `http://127.0.0.1:8767/?view=config`의 HTML·CSS로 다시 캡처했습니다. 브라우저 크기는 1440 × 1200이며, 글꼴 로딩을 기다린 뒤 저장했습니다. 기존 문서 링크를 위해 파일 이름은 유지했습니다.

`14-current-overview.png`는 당시 서버가 조회해 준 실제 환경 상태입니다. 다른 이미지는 현재 화면의 상태 렌더러에 브라우저 응답 예시를 제공하거나 입력창을 열어 만든 **설명용 상태 예시**입니다. 기기 이름·식별자·PID·페어링 정보·오류 문구는 예시이며, 실제 실행 또는 실패를 입증하는 자료가 아닙니다.
